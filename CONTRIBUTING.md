# Contributing

This is a small private project. Issues and small pull requests are welcome.

1. Do not commit `.env`, `data/*.sqlite`, or any API key. Put names in `.env.example` and values only on your own machine.
2. Do not add a confirmed number unless a real page supports it. Leave a number as "check this" when you are not sure.
3. Keep on-screen words in `src/copy.js`. Keep spacing and colors in the files named by `docs/ui-rules.md`.
4. Run `npm test` before you open a pull request. If you change the research code, also run the Python tests from the `ml` folder.
5. Write like you are talking to a person. Short sentences. No secret values in the README.
